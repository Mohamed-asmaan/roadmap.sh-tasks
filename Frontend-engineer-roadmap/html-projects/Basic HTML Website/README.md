# Basic HTML Website

This project is part of the **roadmap.sh Frontend Engineer roadmap** and focuses
on building a **multi-page website using only HTML**.

The goal is to practice semantic HTML, page structure, navigation, and basic
SEO concepts without using CSS or JavaScript.

---

## 📄 Pages Included

- `index.html` – Homepage
- `projects.html` – Projects listing
- `articles.html` – Articles and write-ups
- `contact.html` – Contact page with a form

Each page shares a common navigation bar for consistency.

---

## 🧱 Concepts Practiced

- Semantic HTML elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Multi-page website structure
- Accessible document hierarchy
- SEO meta tags
- Basic form structure
- Clean, maintainable HTML ready for future styling

---

## 🚀 How to Run

1. Open this folder
2. Open `index.html` in any modern browser
3. Navigate between pages using the navbar

No setup or build tools required.
